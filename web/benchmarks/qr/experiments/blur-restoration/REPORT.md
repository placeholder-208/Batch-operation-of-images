# v3.11 局部模糊恢复

结论：在本测试集新增5个成功解码，已加入原流程的末尾。仅处理原先未解决、已有裁剪信息的候选，原先成功的区域不进入恢复。

## 可控验证与真实图片探索

先以可解码图片 curved/image008.jpg 生成已知模糊，确认 FFT 数值往返、恒等滤波及恒定亮度处理正确。已知高斯 σ=2.4 时，模糊图无法解码，使用匹配 PSF 的 Wiener 恢复后读回原内容哈希。这个控制实验只证明实现可工作，已知核比真实场景有利，不能当成未知模糊恢复率。

随后对原算法未解决的20个区域，复用当前 WeChat 检测与裁剪信息，没有使用人工四角。初始50组滤波获得5个结果。将搜索收窄为17组通用粗网格后仍保留这5个，不要求自动判定模糊类型：

- 高斯假设：σ=1、1.5、2、2.5、3，正则项0.01；
- 直线运动假设：长度5、9、13，方向0°、45°、90°、135°，附加σ=0.6，正则项0.02。

这些参数均以最长边384的恢复工作图为单位。FFT采用镜像延拓，保持DC亮度，对Nyquist共轭频点的增益显式对称化。频谱工作数组复用，避免每次滤波重新分配多兆字节数组；每次输出仍是独立的ImageData。恢复仅用于解码，导出裁图继续使用原图像素。

新增分别来自 blurred/image016.jpg（0→3）、image018.jpg（2→3）、image021.jpg（0→1）。它们与标注一对一匹配，且新内容哈希均在其他已成功图片中出现过。没有文字真值，所以不将位置匹配率表述为解码文本正确率。

95张离线结果在 `../../results/local-production-3.11-results.jsonl`。该轮逐图总耗时合计63.27秒；此前v3.10记录为52.22秒。恢复父阶段累计10.77秒，其中准备约0.51秒、滤波9.41秒、解码0.46秒，共处理20个区域、296次滤波。这些是单轮开发机观测，包含初始化和调度差异，不是稳定速度承诺；后续工作数组复用未单独重新计时。

## 预算与错误记录

每图最多3个区域；每区域最多17种滤波，之前另有一次缩小区域的基础解码。区域预算1500ms、整图4500ms，在任务之间检查，不强行中断正在进行的同步滤波或异步解码，实际耗时可能跨过期限。本轮离线测试没有预算跳过、没有运行异常。

单个滤波后让出任务调度，调用现有后台ZXing。当前FFT仍在主线程，慢设备可能短暂卡顿；若实际交互观测表明有必要，再将FFT移入独立Worker。预算限制与缩小的工作分辨率用于控制计算和内存，不保证所有设备都有相同恢复能力。

统计中保留原校正失败/跳过原因为 `geometryReason`。恢复完成仍失败、达到恢复预算和运行异常分别记录，CSV追加区域数、滤波次数和子阶段耗时。`deblur_total` 为父阶段，不与子阶段重复相加。

## 浏览器与界面验证

Chromium实际WASM/Worker解码路径检查10张图片，包括三张新增图片、原曲面增益图片及回归样本，结果符合预期。界面端验证旧设置迁移、图片导入、双码识别、统计JSON/ZIP导出、刷新恢复、二维码遮盖、五标签页与EAN13解码。TPS仍可选，恢复在原校正全部失败后执行。

数值测试、标注审计、采样、CSV兼容与预算/异常测试均通过。新方法仍在同一数据集上选择和评估参数，尚无独立留出集的真实图验证；当前15个剩余位置全部在模糊组，不保证这些核假设适用于任意拍摄模糊。

## 复现

从web目录运行，依赖及 `QR_CANVAS_MODULE` 设置与上级README相同：

```sh
node --test benchmarks/qr/verification.test.mjs benchmarks/qr/experiments/blur-restoration/frequency.test.mjs
node --experimental-vm-modules benchmarks/qr/experiments/blur-restoration/sweep.mjs --synthetic
node --experimental-vm-modules benchmarks/qr/experiments/blur-restoration/sweep.mjs --bounded
node --experimental-vm-modules benchmarks/qr/bench.mjs local-production-3.11
```

探索程序的 `--bounded` 输出基于缓存检测框，带 `cachedDetection` 标志，不代替完整管线评估；全量主指标来自最后一条正式管线命令。合成控制的模糊核是已知的；真实图片测试只使用候选区域和有限假设，不使用标注或正确文本指导恢复。
